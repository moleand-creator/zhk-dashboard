# Продажи в ЖК МБ

HTML-дашборд к проекту по курсу «Визуализация» (вариант 1).

- Светлая версия: [moleand-creator.github.io/zhk-dashboard](https://moleand-creator.github.io/zhk-dashboard/)
- Темная версия: [moleand-creator.github.io/zhk-dashboard/dark](https://moleand-creator.github.io/zhk-dashboard/dark/)

Основной график - 3D-шахматка на three.js: каждый блок - квартира, заливка - продана, стекло - еще в продаже, выступающий блок - продана со скидкой. Дополнительные графики на ECharts: сделки по неделям, доля проданных по корпусам и комнатам, менеджеры. Клик по квартире, неделе, ячейке или менеджеру фильтрует весь дашборд.

Данные: `data.js`, выгрузка из «Продажи ЖК, март-сентябрь 2026.xlsx» (367 квартир, 248 сделок).
